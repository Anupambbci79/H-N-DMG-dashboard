1. Connect

The key is stored only in this browser on this computer. It is never written into this file, so the file can be shared safely. Create a key in your ElevenLabs account under Profile, then API keys.

2. Your voice

Create a clone of my voice

Record yourself in a quiet room, or upload recordings you already have (for example a phone voice memo or an old video's audio). More clean speech gives a better clone: aim for at least one minute, two to three is better. Instant cloning usually needs a paid ElevenLabs plan.

3. Speak

Tap a phrase to speak it. Audio is kept in memory after the first play, so repeats are instant and use no extra credits.

Voice settings and fallback
Voice cloning and speech generation are done by ElevenLabs over the internet, so the text you type is sent to them. Do not type patient identifiers if you use this in clinic.
